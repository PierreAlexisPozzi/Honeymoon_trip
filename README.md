# Lune de Miel Japon & Philippines

Site web pour planifier et suivre notre lune de miel au Japon et aux Philippines (20 Février - 13 Mars 2026).

## Fonctionnalités

- **Planning Journalier** : Détail de chaque journée avec activités et hébergements
- **Points d'Intérêt** : Lieux à visiter classés par ville
- **Carte Interactive** : Visualisation géographique des destinations
- **Convertisseur de Devises** : Conversion EUR/JPY/PHP
- **Services Hôteliers** : Informations sur les hébergements
